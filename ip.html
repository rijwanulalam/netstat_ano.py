Overview

Every device is constantly talking to remote servers. Most of it is normal (updates, websites, cloud apps), but it is rarely visible. exIPcheck reads your ESTABLISHED connections with netstat -ano, keeps only public internet addresses, and asks VirusTotal whether any security vendor has flagged each one and which country it is registered in.

Everything lives in one Python file, netstat_ano.py. Your PC scans and pushes the results to GitHub; a Streamlit dashboard in the cloud displays them.

Features

Live connection capture

Uses built-in netstat -ano. No administrator rights needed.

Public IP filtering

Drops private, loopback and link-local addresses. IPv4 and IPv6.

Reputation and country

Malicious and suspicious counts plus registered country, via VirusTotal API v3.

Quota-friendly

Each IP is cached and re-checked only after a week, so only new IPs cost a request.

24-hour history

Shows every IP seen in the last 24 hours, flagged ones first.

Runs by itself

One command sets up a scan every 15 minutes, and results are pushed to GitHub only when they change.

How It Works

Streamlit Cloud runs on a remote server, so it cannot see your computer's connections. The work is split in two: your PC scans, the cloud only displays.

The same file decides its mode from how you run it:

RunModeWhat it does
python netstat_ano.pyScanScans, updates foreign_ip_status.txt, pushes to GitHub
streamlit run netstat_ano.pyDashboardReads the file and shows it as a table. Never scans.

Usage

CommandWhat it does
python netstat_ano.pyScan once, update the results file, push to GitHub
python netstat_ano.py --loopScan every 15 minutes in the open terminal (Ctrl+C to stop)
python netstat_ano.py --installCreate a Task Scheduler job that scans every 15 minutes
python netstat_ano.py --uninstallRemove that scheduled job
streamlit run netstat_ano.pyOpen the dashboard in your browser

The scheduled task runs under your Windows account: it works while you are signed in (a locked screen counts), and not while you are signed out or the PC is off or asleep. On a laptop, untick the battery-power restrictions on the task's Conditions tab in Task Scheduler.

Configuration

Settings sit at the top of netstat_ano.py.

SettingDefaultMeaning
RECHECK_AFTER_DAYS7Look an IP up again after this many days
SHOW_LAST_HOURS24Show IPs seen within this many hours
MAX_LOOKUPS_PER_RUN20Cap on new VirusTotal lookups per scan
WAIT_BETWEEN_LOOKUPS16Seconds between lookups (free tier: about 4 per minute)
SCAN_EVERY_MINUTES15Interval for --loop and --install (re-run --install after changing)

Output Files

FilePushed?Purpose
foreign_ip_status.txtYesResults table shown on the dashboard
ip_cache.jsonNoRemembers past VirusTotal answers and last-seen times

The script only ever stages foreign_ip_status.txt. As a safeguard, add ip_cache.json and scan_log.txt to a .gitignore.

Security and Privacy

  • Never commit your API key. Keep it in the VT_API_KEY environment variable. If it is ever exposed, generate a new one on your VirusTotal profile.
  • Your results are public if your repo or dashboard is. The table lists the internet addresses your computer connects to. Consider a private repository, and restrict viewers in the app's sharing settings.
  • A flag is a signal, not a verdict. Results can include false positives, and shared hosting or CDN addresses can inherit a bad reputation. Investigate; do not assume compromise.
  • Only monitor machines you own or are authorised to monitor. This tool is for awareness: it blocks nothing and does not replace endpoint protection.

Troubleshooting

Start with scan_log.txt.

SymptomCause and fix
VT_API_KEY environment variable is not setThe script cannot see your key. Run setx, then reopen the terminal. In PowerShell, %VT_API_KEY% does not work; use $env:VT_API_KEY.Length.
Lookup failed (HTTP 401)VirusTotal rejected the key, often a placeholder or typo. Set the real key.
HTTP 429 / rate limitFree-tier limit hit. Remaining IPs are checked on the next scan.
Git push FAILED ... rejected (fetch first)GitHub has commits your PC lacks. Use the latest script (it pulls before pushing) or run git pull --rebase --autostash origin main once.
Vim opens during a manual git pullPress Esc, type :wq, press Enter. To avoid it: git config --global core.editor notepad.
Dashboard says "No data yet"Run a scan first and make sure foreign_ip_status.txt is committed.
Dashboard is out of dateCheck the log says "Pushed", the PC is on and signed in, and Streamlit has finished redeploying (a minute or two).

Limitations and Roadmap

  • Windows only: it relies on netstat -ano output and Task Scheduler.
  • The PC must be on and signed in for the dashboard to stay current.
  • VirusTotal's free tier has per-minute and daily quotas; check their current limits.
  • Only ESTABLISHED TCP connections are captured, so very short-lived connections between scans can be missed.
  • Ideas: email or chat alerts for new flagged IPs, Linux and macOS support, process names per connection, history charts.
